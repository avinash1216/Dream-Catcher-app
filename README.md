# 🌙 Dream Catcher — Let AI Decode Your Dreams

Dreams are windows to the subconscious — mysterious, emotional, and deeply personal.
**Dream Catcher** is your AI companion that helps you understand what your dreams might be trying to tell you.

Whether it’s a flying adventure, a falling moment, or a strange déjà vu, Dream Catcher uses the power of **Gemini AI** to analyze, interpret, and explain the hidden meanings behind your dreams.

---

## ✨ Features

* 🧠 **AI-Powered Dream Interpretation:** Understand the psychology and symbolism behind your dreams.
* 💬 **Personalized Explanations:** Every interpretation is crafted based on your unique dream details.
* 📖 **Dream History:** Keep a log of your dreams to see recurring themes and emotions.
* 🎨 **Beautiful & Calm Interface:** Designed to feel like your personal dream journal.

---

## 🚀 Run Locally

**Prerequisite:** [Node.js](https://nodejs.org/) (v18 or above)

1. **Clone this repository**

   ```bash
   git clone https://github.com/yourusername/dream-catcher.git
   cd dream-catcher
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set your Gemini API Key**
   Create a `.env.local` file in the root directory and add:

   ```bash
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Run the app**

   ```bash
   npm run dev
   ```

5. **Open your browser** and visit
   👉 [http://localhost:3000](http://localhost:3000) to start decoding your dreams.
